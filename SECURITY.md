# Security Policy

## Reporting a Vulnerability

qtop is a cluster monitoring tool that reads system information and does not
process untrusted input. However, if you discover a security vulnerability,
please report it privately by opening a GitHub Security Advisory at:

https://github.com/qtop/qtop/security/advisories/new

Please do not report security vulnerabilities through public GitHub issues.

## Supported Versions

Use the latest release from the `main` branch. The `develop` branch contains
work-in-progress changes that may not be fully tested.

## Preferred Languages

We prefer all communications to be in English.
