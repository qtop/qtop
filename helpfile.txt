qtop - interactive help
Fast, scheduler-independent cluster observability in your terminal.

Navigation

  j / Space      scroll down one screen
  k / Backspace  scroll up one screen
  h / l          scroll left / right
  g / K          jump to the top
  G / J          jump to the bottom
  0 / $          jump to the left / right edge
  R              reset the viewport

View and analysis

  f              filter worker nodes
  s              sort worker nodes
  H              highlight users or queues
  F              toggle full names / numbered node labels
  m              toggle core coloring by user / queue
  p              cycle the colour palettes of palettes.yaml
  Q              expand / collapse the queueing summary
  r              cycle all / real / used core lines
  t              transpose the worker-node matrix
  1 2 3          show / hide sections 1-3 (as -1, -2, -3)
  4              show / hide the accounts totals row (as -4)

Session

  ?              toggle this help screen
  q              quit qtop

Press ? to return to the cluster view. Run qtop --help for CLI options.
